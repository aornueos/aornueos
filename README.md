<h2 align="left">Cybersecurity • Red Team • Creative Systems</h2>

<p align="left">
  I work with a strong focus on <strong>offensive cybersecurity</strong>, penetration testing, vulnerability analysis, and adversarial thinking.

</p>

<p align="left">
